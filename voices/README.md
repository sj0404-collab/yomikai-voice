# voices/ — заготовленные голоса (x-vector .bin, ~8 КБ)

Создаются воркфлоу **Voice-фабрика** из референс-аудио (3–30 с чистой речи через прямую ссылку).
Использовать: **TTS-киоск** → поле `custom_voice` = имя файла без `.bin`.

Голоса крошечные намеренно: вся «тяжесть» — базовая модель (качает раннер, не вы),
а идентичность голоса — 8 КБ x-vector, работает и с эмоциями `[joy]` и т.п. (CustomVoice 0.6B).

Android-приложение «Голос Yomikai» потом подтянет эти же .bin (десятки КБ, а не гигабайты).
